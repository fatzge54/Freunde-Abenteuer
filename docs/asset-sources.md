# Asset-Quellen für Freunde-Abenteuer

Diese Datei listet die wichtigsten freien oder low-cost Quellen für die Erstellung der 3D-Kinderanimationsserie auf. Die Auswahl ist so getroffen, dass sie für Blender, kinderfreundliche Animation, Nature-Environment, Audio und TTS möglichst praktisch ist.

## 1) 3D-Umgebungen, Natur-Assets und Texturen

### Poly Haven
- URL: https://polyhaven.com/
- Art: 3D-Assets, HDRIs, Texturen, Materialien
- Lizenz: CC0 / Public Domain
- Nutzen: Wald, Natur, Boden, Himmel, Licht, atmosphärische Elemente
- Einsatz: Bäume, Felsen, Pflanzen, Lichtstudien, Wetter-Umgebungen

### AmbientCG
- URL: https://ambientcg.com/
- Art: Texturen, PBR-Materialien, Render-Assets
- Lizenz: CC0
- Nutzen: Holz, Gras, Blätter, Boden, Stoffe, Stein, Naturtexturen
- Einsatz: realistische, aber stylisierte Material- und Texturbasis

### OpenGameArt
- URL: https://opengameart.org/
- Art: 2D/3D-Assets, Sound, kleine Props, Grafik-Assets
- Lizenz: gemischt, aber viele Assets sind CC0
- Nutzen: kleinere Props, Low-Poly-Gegenstände, iconische Elemente, Zusatz-Assets
- Einsatz: Beeren, Pilze, Holzsachen, Spielobjekte

### Kenney.nl
- URL: https://kenney.nl/assets
- Art: Stylized 2D/3D Assets, UI, Props
- Lizenz: meist CC0 / frei nutzbar
- Nutzen: Kinderfreundliche stilisierte Objekte
- Einsatz: Möbel, Obst, Werkzeuge, Spiel-Props, kleine Objekte

## 2) Charakterbasis / 3D-Figuren

### MakeHuman
- URL: http://www.makehumancommunity.org/
- Art: 3D-Charaktergenerator für Menschenfiguren
- Lizenz: AGPL / frei nutzbar
- Nutzen: Character-base für Figuren, Anpassung auf kindgerechte Stile
- Einsatz: Lilo, Max, Pippa, Bobo als cartoony human base

### Mixamo
- URL: https://www.mixamo.com/
- Art: 3D-Character-Figuren, Auto-Rigging, Bewegungsclips
- Lizenz: je nach Adobe/Nutzerbedingungen, aber praktisch für kreative Workflows
- Nutzen: schnelle Animationen, Bewegungsvorlagen, Verhaltensclips
- Einsatz: Laufen, Warten, tanzen, springen, Gestik

### Blender (Haupttool)
- URL: https://www.blender.org/
- Art: 3D-Software
- Lizenz: Open Source / frei
- Nutzen: Modellierung, Rigging, Animation, Rendering
- Einsatz: Zentraler Produktionsworkflow

## 3) Musik, SFX und Sounddesign

### Pixabay Music
- URL: https://pixabay.com/music/
- Art: Musik
- Lizenz: CC0
- Nutzen: fröhliche, kindgerechte Hintergrundmusik und Ideen für Moods
- Einsatz: Intro, Spiel, Abenteuer, Abschluss, Festmusik

### Pixabay Sound Effects
- URL: https://pixabay.com/sound-effects/
- Art: SFX
- Lizenz: CC0
- Nutzen: Schritte, Wind, Blätter, Vögel, Lachen, Raumklang
- Einsatz: Wald, Dorf, Regen, Stimmungssounds

### Openverse
- URL: https://openverse.org/
- Art: Musik, Audio, Bilder, Video
- Lizenz: CC0/CC-BY je nach Datei
- Nutzen: lizenzfreie Audio-/Bildquellen für die Serie
- Einsatz: Prüfung und Auswahl von offenen Medien

## 4) Text-to-Speech (deutsch)

### Coqui TTS
- URL: https://github.com/coqui-ai/TTS
- Art: Open-Source TTS
- Lizenz: Open Source
- Nutzen: deutsche Stimmen, lokal nutzbar, frei
- Einsatz: Prototyp-VO, Story-Previews, frühe Audio-Tests

### Google Cloud TTS
- URL: https://cloud.google.com/text-to-speech
- Art: Cloud TTS
- Lizenz: Cloud pricing, kostenlose Test-Credits verfügbar
- Nutzen: hochwertige deutsche Stimmen, API-basierte Generierung
- Einsatz: bessere Sprachqualität als kostenloses TTS, gut für Prototypen

### ElevenLabs
- URL: https://elevenlabs.io/
- Art: AI-Stimme / TTS
- Lizenz: kostenpflichtig / freier Testbereich
- Nutzen: sehr natürliche, emotionale Stimmen
- Einsatz: finale hochwertige Sprecher-Annäherung, wenn Budget verfügbar

## 5) Allgemeine lizenz- und Rechtsprüfung

### Creative Commons
- URL: https://creativecommons.org/licenses/
- Art: Lizenzübersicht
- Nutzen: Prüfung von Lizenzarten und Regeln
- Einsatz: Verifikation, ob ein Asset frei verwendet werden darf

## 6) Empfohlene Reihenfolge für das Projekt

Für dieses Projekt wird empfohlen:
1. Poly Haven + AmbientCG → Natur, Licht, Texturen, Umgebungen
2. MakeHuman + Mixamo → Charaktere und Animationen
3. Pixabay + Openverse → Musik und SFX
4. Coqui TTS → deutsche VO für Prototypen
5. Google Cloud TTS / ElevenLabs → finale Stimmenoption, wenn Qualität entscheidend ist
6. Blender → zentrale Produktionssoftware

## 7) Wichtige Projekt-Notiz
Bei der Verwendung externer Assets sollten immer die Lizenzangaben geprüft werden. Für den Produktions- und Kreativ-Workflow dieses Projekts werden CC0-/Open-Source-Assets bevorzugt. Bei kostenpflichtigen Assets wird die Nutzung in einer zugehörigen Lizenz-Datei dokumentiert.
