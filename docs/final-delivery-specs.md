# Final Delivery Specs & Naming Conventions

Master Video
- Format: ProRes 422 (or DNxHD) - 1920x1080 - 24fps
- Audio: WAV 48kHz 24-bit, Stereo
- Color: Rec.709 or ACES conversion from Filmic
- File name: FA_ep01_master_v01.mov

Web Proxy
- Format: MP4 H.264 - 1920x1080 - CRF 18 - AAC 192kbps
- File name: FA_ep01_web_v01.mp4

EXR Sequences
- Format: OpenEXR Multilayer per shot
- Naming: ep##_shot##_layer_####.exr

Asset Naming
- char_lilo_v01.fbx
- scene_forest_blockout_v01.blend
- audio_ep01_vo_lilo_line001_v01.wav

Metadata
- Jeder Master-Datei beiliegt: METADATA.json mit: authors, version, date, used-assets (links), license
